# 📦 Папка плагінів Lampa

## Як додати плагін

1. **Просто скиньте `.js` файл у цю папку** — він завантажиться автоматично при наступному запуску Lampa.
2. Порядок завантаження: файли сортуються за назвою (природне сортування).
   Щоб задати порядок — використовуйте префікс: `01_мій_плагін.js`, `02_інший.js`

---

## Метадані плагіна (необов'язково)

Якщо додати коментарі на початку `.js` файлу — вони відображаються в логах і `loader.php`:

```js
// @name        Назва плагіна
// @version     1.0.0
// @author      Ваше ім'я
// @description Короткий опис
```

Дивіться `_example_plugin.js` — шаблон готового плагіна.

---

## Як це працює

```
Lampa запускається
    │
    ▼
PluginLoader чекає події Lampa "ready"
    │
    ▼
Запит до plugins/loader.php  ──(PHP є?)──► JSON зі списком файлів
    │ (PHP немає)
    ▼
Запит до plugins/plugins.json  (статичний fallback)
    │
    ▼
Плагіни завантажуються послідовно, один за одним
```

---

## Два режими роботи

### 🟢 Режим PHP (рекомендований, автоматичний)
- Файл `loader.php` автоматично сканує папку
- Достатньо **просто скинути .js файл** — більше нічого робити не треба
- Потрібен веб-сервер з PHP (Apache, Nginx + PHP-FPM)

### 🟡 Режим JSON (статичний, fallback)
- Якщо PHP недоступний — редагуйте `plugins.json` вручну:

```json
{
  "status": "ok",
  "count": 2,
  "plugins": [
    { "file": "plugins/multiplugin.js", "name": "Мультиплагін" },
    { "file": "plugins/мій_плагін.js",  "name": "Мій плагін"   }
  ]
}
```

---

## Файли у папці

| Файл | Опис |
|------|------|
| `loader.php` | PHP-скрипт автосканування (основний режим) |
| `plugins.json` | Статичний список плагінів (fallback) |
| `multiplugin.js` | Менеджер плагінів від спільноти |
| `_example_plugin.js` | Шаблон для розробки свого плагіна |

---

## Відлагодження

Відкрийте **DevTools → Console** у браузері. Всі дії логуються з префіксом `[PluginLoader]`:

```
[PluginLoader] Старт сканування плагінів...
[PluginLoader] Знайдено плагінів: 2 ["Мультиплагін", "Мій плагін"]
[PluginLoader] ✔ Завантажено: plugins/multiplugin.js
[PluginLoader] ✔ Завантажено: plugins/мій_плагін.js
[PluginLoader] Всі плагіни завантажено.
```
